status code 200
زمان ینی همه چی اوکی بوده و عملیات با موفقیت انجام شده زمانی که کاربر درخواست لیست یا جزئیات داشته باشه و حالت دریافت دارد

status code 201
کاربر میخواهد یک ثبت انجام دهد

status code 202
زمانی که درخواست کاربر دریافت شده و درحال پردازش هست اینرو به کاربر برمیگردونیم

status code 301
وقتی کاربر یک مسیری رو صدا زده و این مسیر تغییر کرده و به آدرس دیگه ای منتقل شده ازین استفاده میکنیم

status code 400
سری این کدها ینی یه مشکل از سمت کلاینت وجود دارد

status code 401
کاربر دسترسی به یک آدرس ندارد

status code 403
کاربر لاگین کرده ولی این کاربر به این آدرس دسترسی نداره

status code 404
آدرس وجود نداره یا حذف شده

status code 409
اگر اطلاعاتی که کاربر به آدرس ارسال میکند توسط شخص دیگری تغییر کرده باشد این کد نمایش داده میشه

status code 500
خطای سمت سرور وجود دارد
