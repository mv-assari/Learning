برای ایجاد کانتینر از دستور زیر استفاده میکنیم

docker create --name redisServer1 redis

خروجی یک آی دی هست

برای نمایش کانتینر ها از دستور زیر استفاده میکنیم
البته این دستور برای کانتینر های درحال اجرا هست
docker ps

برای نمایش همه کانتینرهای حتی در حالت متوقف هم از دستور زیر استفاده میکنیم
docker ps -a

برای اجرای کانتینر از دستور زیر استفاده میکنیم که البته به آی دی اون کانتینر برای اینکار نیاز داریم
docker start (Id)

اگر بخواهیم کانتینری رو متوقف کنیم از دستور زیر استفاده میکنیم
docker stop (Id)

برای دیدن لاگ های کانتینر از دستور زیر استفاده میکنیم
docker logs (Id)

دستوری داریم که بلافاصله بعد از ایجاد اون رو استارت کنه
docker run -p (protdocker):(protsystem) --name (nameOFContainer) (nameOfImage)
