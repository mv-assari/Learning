زمانی که ما یک کانتینر ایجاد میکنیم تمام دیتای خودش داخل کانتینر ذخیره میشه
و اگر کانتینر حذف بشه تمام دیتا هم ازبین میره

با استفاده از داکر والیوم ها برای ذخیره سازی این دیتاها استفاده میکنیم
ابتدا یک کانتینر ایجاد میکنیم
سپس با استفاده از دستور زیر وارد کانتینر میشیم
docker exec -t -i (idcontainer) /bin/bash

سپس به دنبال مسیر زیر میگردیم
البته کانتینری که ایجاد کردیم باید از نوع دیتابیس باشه که داخلش دیتا ذخیره بشه

/var/opt/mssql/data

داخل این مسیر فایل های 
ldf , mdf
وجود داره که باید اونو به جای دیگه ای که خودمون قبلا ایجاد کردیم کپی کنیم

برای دیدن والیوم ها از دستور زیر استفاده میکنیم
docker volume ls

برای ساخت والیوم جدید از دستور زیر استفاده میکنیم
docker volume create (nameOfVolume)

برای دیدن مشخصات والیوم از دستور زیر استفاده میکنیم
docker volume inspect (nameOfVolume)

برای حذف والیوم از دستور زیر استفاده میکنیم
docker volume rm (nameOfVolume)

برای تنظیم یک ایمیج برای تنظیم دیتای کانتینر در والیوم مشخص
هنگام ایجاد یک کانتینر که مخصوص دیتابیس هست از این قسمت هم  در دستور ایجاد آن استفاده میکنیم
-v (nameOfVolume):/var/opt/mssql/data
