به صورت پیشفرض وقتی ما سرویس داکر رو راه اندازی میکنیم سه تا شبکه ایجاد میشه
این شبکه ها هم به صورت نرم افزاری ایجاد میشن

شبکه مجازی ایجاد میشه
برای دیدن شبکه ها از دستور زیر استفاده میشه
docker network ls

زمانی که ما کانتینر ایجاد میکنیم به صورت پیشفرض در شبکه 
bridge
ایجاد میشه

برای ایجاد شبکه جدید از دستور زیر استفاده میکنیم
docker network create myNetwork

برای بررسی و پیدا کردن کانتینر که در کدام شبکه هست از دستور زیر استفاده میکنیم
docker network inspect bridge

برای ایجاد کانتینر در شبکه مورد انتخاب از دستور زیر استفاده میکنیم
docker run -d --network myNetwork redis 

اگر کانتینر را بخواهیم ایجاد کنیم که با هیج شبکه ای ارتباط نداشته باشه از شبکه پیشفرض 
none 
که از قبل خود سیستم داکر ایجاد کرده استفاده میکنیم

اگر کانتینری را ساختیم و اگر بخواهیم آنرا به شبکه ای اختصاص بدیم از دستور زیر استفاده میکنیم
نکته ای که هست یک کانتینر همزمان نمیتواند در شبکه وجود داشته باشه
docker network disconnect none (nameOfContainer)
docker network connect (nameOfNetwork) (nameOfContainer)

برای حذف یک شبکه از دستور زیر استفاده کنیم
برای حذف هم باید ابتدا کانتینرها رو خارج یا حذف کنیم سپس شبکه قابل حذف هست
docker network rm (nameOfNetwork)
